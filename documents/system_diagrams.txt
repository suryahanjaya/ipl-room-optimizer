![User Interaction Flow — IPL Room Merging Optimization System](C:\Users\ASUS ZENBOOK\.gemini\antigravity\brain\281b74ca-2b27-4c3e-90a2-1be9dd6e4054\user_interaction_diagram_1773137577412.png)

### Flow Path A — Web Interface (Primary)

```mermaid
sequenceDiagram
    actor User as University Admin
    participant Browser as Web Browser
    participant Flask as Flask Server<br/>src/web/server.py
    participant Worker as Background Thread<br/>optimization_worker()
    participant Engine as IPL Optimizer<br/>src/ipl_optimizer.py
    participant FS as File System<br/>uploads/ & results/

    User->>Browser: Open localhost:5000
    Browser->>Flask: GET /
    Flask-->>Browser: index.html (Welcome Page)
    User->>Browser: Click "Enter Application"

    Note over User,Browser: Step 1: Upload Data File

    User->>Browser: Drag & drop .xlsx/.csv file
    Browser->>Flask: POST /api/upload (multipart)
    Flask->>FS: Save to uploads/input_data.xlsx
    Flask-->>Browser: { success: true, filepath }

    Note over User,Browser: Step 2: Select Mode & Start

    User->>Browser: Select Fast / Deep mode
    User->>Browser: Click "Start Merging"
    Browser->>Flask: POST /api/merge { filepath, mode }
    Flask->>Worker: Spawn thread (task_id = UUID)
    Flask-->>Browser: { task_id }

    Note over Worker,Engine: Step 3: Background Processing

    Worker->>Engine: subprocess: python ipl_optimizer.py -i ... -o ...
    Engine->>FS: Read input file (Pandas)
    Engine->>Engine: process_exam_data()
    loop For each (Shift, Campus) group
        alt size ≤ threshold
            Engine->>Engine: MILPRoomOptimizer.solve()
        else size > threshold
            Engine->>Engine: GreedyBinPacker.solve()
        end
    end
    Engine->>FS: Write Result_*.xlsx
    Worker->>Worker: export_results_to_json()

    Note over Browser,Flask: Step 4: Poll Progress

    loop Every 1 second
        Browser->>Flask: GET /api/status/<task_id>
        Flask-->>Browser: { progress, message }
    end
    Flask-->>Browser: { status: completed, result: JSON }

    Note over User,Browser: Step 5: View & Download Results

    Browser->>Browser: Render summary cards, detail cards
    User->>Browser: Filter by Shift / Campus
    User->>Browser: Click room tags for details
    User->>Browser: Click "Download Excel"
    Browser->>Flask: GET /results/Result_*.xlsx
    Flask->>FS: Read result file
    Flask-->>Browser: Excel file download
```
